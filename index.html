Selected work

Predicting surgical supply pick lists

Healthcare, Snowflake Cortex

A multi-label model that predicts which supplies a surgery will need, conditioned on surgeon, procedure, and facility. The real data sits behind strict contractual limits, so I designed a privacy-safe profiling workflow with PHI exclusion and small-cell suppression, and used synthetic data to build and validate the pipeline without direct access to patient records.

  • Snowflake Cortex
  • Multi-label classification
  • Python
  • SQL
  • Synthetic data

Sensor monitoring platform on AWS

IoT, event-driven cloud architecture

A cloud platform that monitors temperature and CO₂ sensors across apartment communities, with event-driven processing on SNS and Lambda, storage in RDS, and Streamlit dashboards on ECS. I worked on post-deployment verification: pytest smoke tests, CloudWatch Synthetics canaries, dead-letter queues, and an agent-driven verification step.

  • AWS Lambda
  • SNS
  • RDS
  • ECS
  • Streamlit
  • CloudWatch
  • pytest

Multi-tenant API platform

Backend, data security, developer tooling

A Python API monorepo built on Poetry workspaces. I worked through an incremental migration to PostgreSQL row-level security for tenant isolation, and set up AI-written pull request summaries and changelogs with GitHub Actions and the Anthropic API.

  • Python
  • PostgreSQL RLS
  • Poetry
  • GitHub Actions
  • Anthropic API
